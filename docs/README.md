## 프로젝트 아키텍처

### 기술 스택
- **백엔드**: NestJS, TypeORM, PostgreSQL
- **프론트엔드**: Next.js, React, TypeScript
- **공유 패키지**: TypeScript 인터페이스 및 타입 정의

### 주요 기능
1. **사용자 관리**: 회원가입, 로그인, 프로필 관리
2. **커플 관리**: 커플 연결, 기념일 관리
3. **데이트 기록**: 포스트 작성, 이미지 업로드, 감정 표현
4. **소셜 기능**: 좋아요, 북마크, 댓글
5. **채팅**: 실시간 메시징
6. **알림**: 실시간 알림 시스템
